Лид №4. Тел./WhatsApp: **+7 981 962-90-49**. Сейчас только группа ВК (`vk.com/club197317134`).

**Почему высоко.** Есть только ВК, 52 отзыва, и в отзывах жалуются на общение с администратором. Онлайн-запись снимает часть звонков и переписки.

**Осторожно.** Про жалобы на администратора не пишите ни в сообщении, ни на сайте. Говорите о пользе: запись без звонков, меньше нагрузки на администратора.

Сайт — один файл `index.html`, копия для отправки: [`dlya-otpravki/Neroli-studiya-krasoty.html`](../dlya-otpravki/Neroli-studiya-krasoty.html). Скрины: `screens/L4-neroli-glavnaya.png` (главная) и `screens/L4-neroli-zayavka.png` (заявка в Telegram).

**1. Первое сообщение** (текст + скрин `L4-neroli-glavnaya.png`)

> Здравствуйте! Вы студия «Нероли» на Ветеранов, 143? Увидел, что запись у вас только по телефону и через ВК. Сделал пример сайта: клиентка сама выбирает мастера и свободное время, а накануне ей приходит напоминание. Администратору меньше звонков. Можно скину посмотреть?

**2. После ответа «да»**

> Вот пример 👇 [файл или ссылка]

> Добрый день! Напомню про сайт с онлайн-записью для «Нероли». Если неактуально, напишите «нет», больше не побеспокою.

## Как отправлять

1. Перед отправкой проверьте, что у номера есть WhatsApp или Telegram (добавьте в контакты и откройте чат).
2. **Первое сообщение**: только текст и один скрин `L4-neroli-glavnaya.png` из папки `screens/`. Файл и ссылку не отправляйте.
3. Ответили «да» или «покажите»: отправьте файл `dlya-otpravki/Neroli-studiya-krasoty.html` (или ссылку, если выложите сайт на Netlify) и сообщение 2.
4. Молчат 2–3 дня: одно напоминание (сообщение 3), и больше не пишите.
5. Отметьте статус в `leads/Leads-40.xlsx`.

В демо цены, часы, мастера придуманы, сверху пометка «Демо-версия». Запись показательная: заявка никуда не уходит, а показывает, как она придёт в Telegram. Подключение к боту делается по схеме [`shinomontazh-bot/bot.py`](../shinomontazh-bot/bot.py) после согласия.
