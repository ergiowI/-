3. Ответили «да» или «покажите»: отправьте файл `dlya-otpravki/Massazh-Olga-Leninskiy.html` (или ссылку, если выложите сайт на Netlify) и сообщение 2.

5. Отметьте статус в `leads/Leads-40.xlsx`.
