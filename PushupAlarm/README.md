# Отжимайся: будильник, который не выключить без отжиманий

Нативное приложение для iPhone на AlarmKit (нужна **iOS 26+**). Звонит как обычный
будильник: на заблокированном экране и в беззвучном режиме.

## Как это работает

1. В заданное время звонит системный будильник с кнопками **«Стоп»** и **«Отжаться»**.
2. **«Стоп»** не спасает: через 60 секунд звонит снова. И так бесконечно.
3. **«Отжаться»** открывает экран со счётчиком. Приложение пищит, пока не начнёшь.
4. Телефон кладёшь на пол экраном вверх, верхним краем под лицо. Каждое опускание до
   экрана засчитывается датчиком приближения, номер говорится вслух.
5. Пока норма не сделана, в системе всегда висит повторный будильник на ближайшие
   1–2 минуты. Закрыл приложение или заблокировал телефон: он зазвонит.
6. Сделал норму, и все повторы отменяются. Завтра всё сначала.

## Установка (Mac + Xcode 26)

```bash
brew install xcodegen
cd PushupAlarm
xcodegen          # создаст PushupAlarm.xcodeproj
open PushupAlarm.xcodeproj
```

В Xcode:

1. Выбери таргет **PushupAlarm**, вкладка **Signing & Capabilities**.
2. **Team**: свой Apple ID (Add Account…, подойдёт бесплатный).
3. **Bundle Identifier**: поменяй `com.example.pushupalarm` на что-нибудь своё,
   например `com.vasya.pushupalarm`.
4. Подключи айфон кабелем, выбери его сверху и нажми ▶︎ Run.
5. На айфоне: **Настройки → Конфиденциальность и безопасность → Режим разработчика**
   включить. Потом **Настройки → Основные → VPN и управление устройством**, доверять
   своему сертификату.
6. При первом запуске разреши доступ к будильникам.

С бесплатным Apple ID приложение работает 7 дней, потом просто нажми Run ещё раз.
С платным аккаунтом разработчика срок год.

## Проверка

В приложении есть кнопка «Проверить: зазвонит через 1 минуту». Нажми, заблокируй
телефон и попробуй отделаться кнопкой «Стоп».

## Файлы

| Файл | Что делает |
|---|---|
| `AlarmService.swift` | ставит и отменяет будильники, цепочка повторов |
| `AlarmIntents.swift` | что происходит по кнопкам «Стоп» и «Отжаться» |
| `WorkoutSession.swift` | счёт отжиманий по датчику приближения, писк, голос |
| `AlarmSound.swift` | генерирует звук писка прямо в коде |
| `ContentView.swift` | настройки: время, число отжиманий |
| `WorkoutView.swift` | экран со счётчиком |

## Честные лазейки

- Датчик можно обмануть ладонью, если держать её у экрана дольше 0,25 с.
- Можно удалить приложение или забрать у него доступ к будильникам в Настройках.

От себя не убежишь 🙂
