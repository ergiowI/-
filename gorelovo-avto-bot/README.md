# Автосервис Горелово, Заречная ул., 3: Telegram-бот записи

Лид №7 из `leads/Leads-40.xlsx`. Тел./WhatsApp: **+7 981 860-61-04**. Сайт у них есть (uCoz, `gorelovosto.ucoz.net`), поэтому предлагаем **Telegram-бота**.

**Что делает бот.** Клиент выбирает класс машины, работу и время и видит цену заранее. Если при ремонте нашли что-то ещё, клиенту приходит фото и цена с кнопкой «Согласовать». Это пример сообщения в демо, в `bot.py` эта функция пока не реализована: её делаем после согласия. Через полгода бот сам зовёт клиента на ТО.

**Осторожно.** Рейтинг у них 3.7★, но про него не пишите. Пишите о пользе: клиенты видят, за что платят.

**3. Если молчат 2–3 дня (один раз)**

## Файлы

| Файл | Что это |
|---|---|
| `demo.html` | Демо для владельца: мини-приложение записи в рамке телефона и чат владельца, куда падает заявка. Страницы: Запись, Цены, Мои записи, Контакты |
| `webapp/index.html` | То же мини-приложение для запуска внутри Telegram (собирается из `demo.html` командой `./build_webapp.sh`) |
| `bot.py` | Бот (aiogram 3): запись через мини-приложение или по шагам в чате, квитанция, «Мои записи», отмена, напоминание за 2 часа, кнопки «Подтвердить / Отказать» у владельца, `/today`, `/tomorrow`, рассылка `/all` и напоминание о ТО через полгода |
| `banner.png`, `avatar.png` | Картинка на /start и аватарка бота |

Услуги, цены и часы задаются в `CONFIG` в начале `bot.py` и в `demo.html`. Сейчас они придуманы, сверху демо стоит пометка «Демо-версия». Запуск такой же, как у [`shinomontazh-bot`](../shinomontazh-bot/README.md#запуск): токен от @BotFather, chat id владельца, `webapp/index.html` выложить на Netlify.

## Как отправлять

1. Перед отправкой проверьте, что у номера есть WhatsApp или Telegram.
2. **Первое сообщение**: текст и скрин `screens/L7-gorelovo-avto-glavnaya.png`. Файл и ссылку не отправляйте.
3. Ответили «да»: отправьте второй скрин `screens/L7-gorelovo-avto-zayavka.png` (так заявка приходит владельцу) и сообщение 2. Демо-файл `dlya-otpravki/Avtoservis-Gorelovo-bot.html` работает только в браузере, в предпросмотре WhatsApp — нет. Лучше всего запустить бота и дать ссылку `t.me/...`, чтобы владелец сам записался для пробы.
4. Молчат 2–3 дня: одно напоминание (сообщение 3), и больше не пишите.
5. Отметьте статус в `leads/Leads-40.xlsx`.
