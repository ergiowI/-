# Бот записи для шиномонтажа (демо для портфолио)

Telegram-бот онлайн-записи: клиент выбирает услугу, дату и свободное время, владелец подтверждает запись в один клик.
Легко переделывается под другую нишу (груминг, салон, детский центр) правкой одного файла `config.yaml`.

**Стек:** Python 3.11+, aiogram 3, SQLite, python-dotenv, PyYAML.

## Возможности
- **Клиент:** `/start`, запись (услуга → дата на 7 дней → время → имя → телефон кнопкой → подтверждение), «Мои записи» с отменой, «Контакты», напоминание за 2 часа.
- **Владелец:** уведомление о новой записи с кнопками «Подтвердить» / «Отменить», клиент получает решение; `/today` и `/week`.
- **Без двойных записей:** показываются только реально свободные слоты, а при создании записи время проверяется ещё раз в транзакции SQLite.

## 1. Получить токен у @BotFather
1. Откройте в Telegram [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Задайте имя и username (должен заканчиваться на `bot`).
3. Скопируйте выданный токен вида `123456:ABC...`.

## 2. Узнать свой chat id
Напишите боту [@userinfobot](https://t.me/userinfobot), он ответит вашим `Id`, это и есть `OWNER_CHAT_ID`.
Затем обязательно откройте своего бота и нажмите **Start**, иначе он не сможет вам писать.

## 3. Запуск
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # впишите BOT_TOKEN и OWNER_CHAT_ID
python -m bot
```
Тесты: `pytest`

## 4. Как поменять нишу (только `config.yaml`)
- `business` — название, адрес, телефон;
- `working_hours` — часы работы по дням (0 = пн … 6 = вс), нет дня значит выходной;
- `services` — список услуг: `id` (латиницей, уникальный), `name`, `duration_minutes`, `price`;
- `slot_step_minutes`, `booking_days_ahead`, `reminder_hours_before` — шаг сетки, горизонт записи, время напоминания.

Пример для груминга: замените блок `services` на «Стрижка — 90 мин — 2500 ₽», «Гигиенический — 60 мин — 1500 ₽» и поменяйте `business`.
Токен и chat id хранятся только в `.env` (он в `.gitignore`).

## Структура
```
bot/config.py        загрузка config.yaml и .env
bot/slots.py         расчёт свободных слотов (чистые функции)
bot/db.py            SQLite, защита от двойной записи
bot/handlers/client.py  сценарий клиента
bot/handlers/owner.py   владелец: подтверждение, /today, /week
bot/reminders.py     напоминания за 2 часа
tests/test_slots.py  тесты слотов, БД и напоминаний
```

## «А если двое запишутся на одно время?»
Два уровня защиты: (1) `slots.free_slots` не показывает занятые интервалы; (2) `Database.create_booking` выполняет проверку пересечения и вставку внутри `BEGIN IMMEDIATE`, поэтому второй получит «время только что заняли» и список других дат.
Подтверждённые напоминания шлются только по записям со статусом «подтверждена»; отменённая запись освобождает время.
