# Сайт-визитка шиномонтажа (шаблон для портфолио)

Чистые HTML, CSS и JS, без фреймворков и сборки. Откройте `index.html` в браузере.

## Как переделать под другую нишу
- **Тексты, цены, отзывы, адрес, ссылка на бота** — только объект `SITE` в `js/config.js`.
- **Цвета** — CSS-переменные в начале `css/style.css`.
- **Кнопка «Записаться»** ведёт на `SITE.botLink` — замените `ИМЯ_БОТА` на username вашего бота.
- **Фото работ** — в `SITE.works` вместо подписи впишите путь к картинке (`img/1.jpg`).
- **Карта** — координаты в `SITE.map` (OpenStreetMap, без ключей).

Отзывы в шаблоне выдуманные и помечены как демо. Вёрстка адаптивная (mobile-first), на телефоне кнопка записи закреплена внизу.
Публикация: GitHub Pages или любой статический хостинг.
