# Сайт шиномонтажа (шаблон для портфолио)

Чистые HTML, CSS и JS, без фреймворков и сборки. Откройте `index.html` в браузере.

## Страницы
| Файл | Что внутри |
|---|---|
| `index.html` | Главная: шина с маркировкой, краткий прайс, «Почему мы», шаги визита, отзывы |
| `services.html` | Таблица цен по радиусам, доп. услуги, **калькулятор стоимости**, FAQ |
| `storage.html` | Сезонное хранение: тарифы, что входит |
| `gallery.html` | Наши работы с фильтром по типу (фото-заглушки) |
| `contacts.html` | Адрес, телефон, часы работы, **«Сейчас открыто / закрыто»** по Москве, карта |

Сверху автоматически меняется **сезонный баннер** (весна / осень / межсезонье).

## Как переделать под другую нишу
Весь контент, цены, цвета и картинка ниши лежат в **одном файле** `js/config.js`:
- тексты страниц, услуги, отзывы, часы работы, ссылка на бота (`botLink`);
- `calc`: таблица цен и калькулятор (строки × варианты: «радиус × тип авто» или «размер питомца × услуга»);
- `art`: картинка в шапке (`"tire"` или `{ emoji: "🐾" }`), `theme`: цвета и шрифты (переменные из `css/style.css`).

**Готовый пример другой ниши:** `examples/grooming.config.js` (груминг-салон, светлая тема).
Скопируйте его в `js/config.js`, и весь сайт станет груминговым без единой правки кода.

## Демо одним файлом
```bash
python tools/build_demo.py                                                   # demo/site.html (шиномонтаж)
python tools/build_demo.py --config examples/grooming.config.js demo/grooming.html  # груминг
```
Страницы переключаются по `#якорю`, файл можно отправить клиенту. `demo/bot.html` — симулятор бота с переключателем ниш.

## Портфолио
В `portfolio/` лежат скриншоты, видео работы бота (`bot-demo.mp4`) и тексты кейса и сообщений клиентам (`CASE.md`).

Отзывы выдуманы и помечены как демо. Публикация: GitHub Pages или любой статический хостинг.

## Тесты
Сам сайт работает без сборки и зависимостей, Node нужен только для тестов в браузере.
```bash
npm install
npx playwright install chromium
npm test
```
49 тестов (`tests/`), запускаются в настоящем Chromium:
- **site.test.js**: каждая страница открывается без ошибок JS, меню и кнопка записи на месте; нет горизонтальной прокрутки на 375 и 1280 px; меню ☰ на телефоне;
  калькулятор (цены, «за колесо» × 4, время работы, недоступные радиусы для кроссовера); фильтр галереи;
  «Открыто / Закрыто» по московскому времени (будни, выходные, ночь, утро); сезонный баннер; демо в одном файле и его актуальность; груминг-конфиг (тексты, светлая тема, калькулятор, выходной).
- **bot-demo.test.js**: симулятор бота: запись, занятые слоты, гонка за одно время, повторный клиент, перенос, оценка, `/stats`, переключение на груминг.

На GitHub тесты запускаются автоматически при каждом push (`.github/workflows/tests.yml`).
