# Генераторы демо

Все демо-сайты и демо-боты собираются из этих скриптов. Под нового клиента не нужно писать HTML: достаточно добавить в список его услуги, цены, цвета и тексты.

| Файл | Что делает |
|---|---|
| `tpl.py` | Шаблон сайта: один HTML-файл, пометка «Демо-версия», онлайн-запись. Без JS вместо формы кнопка WhatsApp |
| `sites.py` | Список сайтов (лиды без сайта): №1 Бикар, №3 Алло Сервис, №4 Нероли, №5 BACKENBART |
| `bottpl.py` | Шаблоны бота: `demo.html` (мини-приложение в рамке телефона + чат владельца), `bot.py` (aiogram 3), баннер и аватарка |
| `bots.py` | Список ботов (у лида уже есть сайт): №2, 6, 7, 8, 9, 10 |
| `screens.js` | Скрины для сообщений и проверка, что запись работает |

## Новый лид

1. Сайта нет → скопировать блок `SITES.append(dict(...))` в `sites.py`. Сайт есть → блок `BOTS.append(dict(...))` в `bots.py`.
2. Поменять в копии: `slug` (папка), `send` (имя файла в `dlya-otpravki/`), название, адрес, телефон, цвета (`vars`), тексты, услуги и цены (`engine.services`). Ближе всего по нише брать: шиномонтаж — Бикар / King Service, массаж — Ольга / Солнечный город, салон — Нероли, барбершоп — BACKENBART, ремонт — Алло Сервис / Ремонт техники, автосервис — Горелово.
3. Собрать (из корня репозитория):
   ```bash
   python3 tools/sites.py новый-slug          # сайт
   python3 tools/bots.py новый-slug           # бот
   sh новый-slug/build_webapp.sh              # только для бота: webapp/index.html
   node tools/screens.js site новый-slug L11-imya   # или: bot новый-slug L11-imya
   ```
4. Написать `новый-slug/README.md` с сообщениями (образец — README любой готовой папки) и добавить строку в `dlya-otpravki/README.md`.

Без аргументов скрипты пересобирают все свои папки. Если меняли файл в папке руками, правку нужно перенести и в генератор, иначе она пропадёт при пересборке.
