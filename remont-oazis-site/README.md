2. **Первое сообщение**: только текст и один скрин `L6-remont-oazis-glavnaya.png` из папки `screens/`. Файл и ссылку не отправляйте.
3. Ответили «да» или «покажите»: отправьте файл `dlya-otpravki/Remont-tehniki-Oazis-of12.html` (или ссылку, если выложите сайт на Netlify) и сообщение 2.
