# Плейбук: как найти клиента и продать бота записи

Пошаговый «скрипт» работы с точками из таблицы (`top10.xlsx`). Первый пример — шиномонтаж на Таллинском ш., 25А, всё для него лежит в папке [`shinomontazh-bot/`](shinomontazh-bot/).

## 0. Порядок работы с одной точкой

1. Выбрать точку из таблицы и прочитать колонки «Почему особый шанс» и «Что предложить».
2. Сделать демо под эту точку (бот или мини-приложение), см. раздел 2.
3. Запустить демо-бота у себя, проверить, что он отвечает (раздел 5).
4. Написать первое сообщение (раздел 3).
5. Ждать ответа. Если молчит 2–3 дня, отправить одно напоминание.
6. После «да»: созвониться, собрать данные (раздел 7), настроить бота под точку, перенести на сервер.
7. Отметить статус в таблице: `Не писал → Написал → Ответил → Демо смотрел → Договорились / Отказ`.

## 1. Профиль в Telegram (один раз)

- **Имя:** настоящее, без «Боты | Сайты 🚀».
- **Фото:** ваше нормальное, с видимым лицом.
- **О себе:** «Боты записи и сайты для автосервисов в СПб. Примеры 👇».
- **Канал в профиле:** «Примеры работ», 3–6 постов. Видео демо, скрин заявки мастеру, как проходит работа. Всё честно подписано как «пример», пока нет реальных клиентов.
- **Номер телефона скрыт:** Конфиденциальность → Номер телефона → «Никто».
- Аккаунт не новый. Новые аккаунты, которые пишут незнакомым, быстро получают ограничение.

## 2. Демо под точку

Что делать под каждую нишу (из таблицы):

| Ниша | Что показать |
|---|---|
| Шиномонтаж | Запись + цена по радиусу, фиксируется до визита |
| Автомойка / детейлинг | Работы «до/после» + запись на время |
| Груминг | Запись с породой + напоминание «пора на стрижку» через 1–2 мес. |
| Салон красоты | Запись к мастеру + счётчик акции «5-я процедура бесплатно» |
| Детский центр / йога | Расписание + запись на пробное занятие + напоминание |

**Правило:** в демо — адрес и название точки, всё остальное (цены, часы, ответы в FAQ) помечено как примерное. Владелец сразу заметит чужие часы, поэтому заранее говорите: «Это пример, поставлю ваши».

Готовые файлы для шиномонтажа:
- `shinomontazh-bot/bot.py` — бот;
- `shinomontazh-bot/webapp/index.html` — мини-приложение (выкладывается на Netlify);
- `shinomontazh-bot/banner.png`, `avatar.png` — картинки для бота;
- `shinomontazh-bot/demo.html` — то же приложение для просмотра в браузере.

## 3. Сообщения

### Главные правила
- **Одно сообщение**, не три подряд.
- **Под конкретную точку:** адрес и деталь из отзывов. Одинаковый текст разным людям — признак спама.
- **Без цены**, пока не спросили. Без «недорого, договоримся».
- **Дайте посмотреть:** лучше всего картинка или видео-кружок с подписью-текстом.
- **Ссылка:** в Telegram можно и в первом сообщении. В WhatsApp только после ответа.
- **Лёгкий отказ:** «если не актуально, напишите „нет“». Тогда человек ответит «нет», а не нажмёт «Спам».

### Шаблон 1 — первое сообщение (картинка/кружок + подпись)
> Здравствуйте! Вы же [ниша] на [адрес]? Увидел, что [проблема: нет онлайн-записи / споры из-за цены в отзывах / только группа ВК]. Сделал под вас бота в Telegram: [1 фраза, что он делает для клиента], а вам приходит готовая заявка. Показать, как работает? Это 30 секунд.

### Шаблон 2 — после ответа «да»
> Вот он вживую, можете сами записаться для пробы 👇
> https://t.me/[имя_бота]
> Нажмите «Старт», потом внизу «Записаться онлайн».
> Цены и часы сейчас примерные, поставлю ваши. Запуск за 1–2 дня. Удобнее созвониться или подъехать к вам?

### Шаблон 3 — когда он записался для пробы (заявка придёт вам)
> Вижу, вы записались на [день, время] 🙂 Вот так же вам будут приходить заявки от клиентов: с ценой и телефоном, с кнопками «Подтвердить / Отказать».

### Шаблон 4 — напоминание через 2–3 дня (один раз)
> Добрый день! Напомню про бота записи: https://t.me/[имя_бота]
> Если сейчас не актуально, просто напишите «нет», больше не побеспокою 🙂

### Эксперимент
Половине точек писать со ссылкой, половине с картинкой без ссылки. Через неделю сравнить, где ответов больше.

## 4. Чтобы не забанили

**WhatsApp**
- давний номер, заполненный профиль;
- пишите руками, без рассылок и расширений;
- в первом сообщении без ссылок;
- не больше 5–10 новых людей в день, пауза 20–30 минут;
- писать в будни с 11 до 16.

**Telegram**
- те же правила, но ссылка на бота допустима;
- если пишут «Вы ограничены», проверьте в @SpamBot, там видно, когда снимут.

**Лучше всего** подъехать лично и показать демо на телефоне, если точка рядом.

## 5. Запуск бота на Mac

### Один раз
1. **@BotFather** → `/newbot` → имя → юзернейм (на `_bot`) → получить токен.
   `/setuserpic` → отправить `avatar.png` **как фото**.
   `/setdescription` → короткое описание.
2. **@userinfobot** → «Старт» → запомнить число `Id`. Это ваш ADMIN_CHAT_ID, на него приходят заявки.
3. Скачать репозиторий: GitHub → ветка `claude/kind-mccarthy-10ph4f` → **Code → Download ZIP** → распаковать.
4. **Netlify:** app.netlify.com → прокрутить до «Загрузите файлы вашего проекта» → перетащить папку `webapp`. Адрес приложения копировать **из адресной строки** открытого сайта (Cmd+L, Cmd+C). Название на странице Netlify может быть переведено Safari, его не перепечатывать.
5. Терминал:
   ```
   cd "$(dirname "$(find ~/Downloads ~/Desktop -name bot.py -path '*shinomontazh-bot*' -not -path '*/.venv/*' 2>/dev/null | head -1)")"
   python3 -m venv .venv
   source .venv/bin/activate
   pip install "aiogram==3.*"
   ```
6. Создать значок «Запустить бота» на рабочем столе (поменять ID и адрес на свои):
   ```
   cat > ~/Desktop/Запустить\ бота.command <<'EOF'
   #!/bin/zsh
   cd "$(dirname "$(find ~/Downloads ~/Desktop -name bot.py -path '*shinomontazh-bot*' -not -path '*/.venv/*' 2>/dev/null | head -1)")" || exit 1
   source .venv/bin/activate
   if [ ! -s .token ]; then read "T?Вставьте токен от BotFather: "; print -r -- "$T" > .token; chmod 600 .token; clear; fi
   export BOT_TOKEN="$(cat .token)"
   export ADMIN_CHAT_ID="1958460223"
   export WEBAPP_URL="https://joyful-begonia-efb755.netlify.app"
   echo "✅ Бот запущен. Не закрывайте это окно. Остановить: Ctrl+C"
   caffeinate -i python bot.py
   EOF
   chmod +x ~/Desktop/Запустить\ бота.command
   ```

### Каждый раз
Двойной клик по «Запустить бота». Окно не закрывать, крышку ноутбука не закрывать.
Бот работает, **только пока ноутбук включён и не спит**. Для реального клиента нужен VPS (раздел 7).

### Частые ошибки
| Что видно | Причина | Что делать |
|---|---|---|
| `invalid literal for int() ... 'ваше_число...'` | в команду вставлена заглушка | вставить настоящие цифры из @userinfobot |
| `Unauthorized` / `Not Found` | токен неверный, заглушка или старый после `/revoke` | `rm .token` в папке бота и запустить значок заново с новым токеном |
| `SSL` / `CERTIFICATE_VERIFY_FAILED` | Python с python.org без сертификатов | `open "/Applications/Python 3.14/Install Certificates.command"` |
| команды печатаются вперемешку с логами | старый бот ещё работает | закрыть окно Терминала целиком («Завершить»), открыть новое |
| `cd: no such file or directory` | неверный путь | использовать команду с `find` выше или перетащить папку в Терминал |
| бот молчит на `/start` | программа не запущена | двойной клик по значку |

### Безопасность
- **Токен — это ключ от бота.** Не показывайте его на скринах, перед скрином выполните `clear`.
- Если токен засветился: @BotFather → `/revoke` → новый токен → `rm .token` → запустить значок.
- Токен не храните в заметках, его всегда можно посмотреть в @BotFather командой `/token`.

## 7. После «да»

### Что спросить у владельца
- точный прайс: типы машин, радиусы, услуги, доп. услуги;
- часы работы и выходные;
- сколько машин одновременно (число постов, `SLOT_CAPACITY` в `bot.py`);
- кто получает заявки: его Telegram, чтобы взять ID из @userinfobot;
- нужен ли чат для нескольких мастеров (тогда группа и ID группы).

### Что сделать
1. Поменять `PRICES`, `ADDRESS`, `WORK_HOURS`, `SLOT_CAPACITY` в `bot.py` и `PRICES` в `demo.html`, затем `./build_webapp.sh` и заново загрузить `webapp` на Netlify.
2. Сделать нового бота **на владельца** или передать ему текущего (@BotFather → `/mybots` → Transfer ownership).
3. Перенести на **VPS** (Timeweb Cloud / Beget / Selectel, около 200–300 ₽/мес), чтобы работал круглосуточно.
4. Ссылку на бота поставить в карточку на Яндекс Картах / 2ГИС, распечатать QR на точку.

### Цена (ориентир)
- настройка бота: от 5 000 ₽ для первого клиента, чтобы получить кейс; дальше поднимать;
- поддержка + сервер: 500–1 000 ₽/мес (смена цен, рассылки, сервер включён).

### После запуска
- Попросить разрешения сделать пост-кейс в канал с названием точки.
- Через 2–4 недели предложить следующий шаг: сайт-страницу с записью для клиентов без Telegram.
