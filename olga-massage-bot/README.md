# Массажист Ольга, Ленинский пр., 74к3: Telegram-бот записи

Лид №2 из `leads/Leads-40.xlsx`. Тел./WhatsApp: **+7 981 717-01-00**. Сайт у Ольги есть (Wix, `lelka-90.wixsite.com/sonatamassage`), поэтому предлагаем не новый сайт, а **Telegram-бота рядом с ним**.

**Что делает бот.** Клиентка сама записывается, может сразу купить курс из 5 или 10 сеансов. Накануне бот напоминает о сеансе, после каждого пишет «сеанс 4 из 10, записаться на следующий?», а через неделю без записи спрашивает о самочувствии.

**3. Если молчат 2–3 дня (один раз)**

> Добрый день, Ольга! Напомню про бота записи с напоминаниями. Если неактуально, напишите «нет», больше не побеспокою.

## Файлы

| Файл | Что это |
|---|---|
| `demo.html` | Демо для владельца: мини-приложение записи в рамке телефона и чат владельца, куда падает заявка. Страницы: Запись, Цены, Мои записи, Контакты |
| `webapp/index.html` | То же мини-приложение для запуска внутри Telegram (собирается из `demo.html` командой `./build_webapp.sh`) |
| `bot.py` | Бот (aiogram 3): запись через мини-приложение или по шагам в чате, квитанция, «Мои записи», отмена, напоминание накануне, кнопки «Подтвердить / Отказать» у владельца, `/today`, `/tomorrow`, рассылка `/all`, учёт курсов (сеанс N из 10) и приглашение через неделю |
| `banner.png`, `avatar.png` | Картинка на /start и аватарка бота |

Услуги, цены и часы задаются в `CONFIG` в начале `bot.py` и в `demo.html`. Сейчас они придуманы, сверху демо стоит пометка «Демо-версия». Запуск такой же, как у [`shinomontazh-bot`](../shinomontazh-bot/README.md#запуск): токен от @BotFather, chat id владельца, `webapp/index.html` выложить на Netlify.

2. **Первое сообщение**: текст и скрин `screens/L2-olga-glavnaya.png`. Файл и ссылку не отправляйте.
3. Ответили «да»: отправьте второй скрин `screens/L2-olga-zayavka.png` (так заявка приходит владельцу) и сообщение 2. Демо-файл `dlya-otpravki/Massazh-Olga-bot.html` работает только в браузере, в предпросмотре WhatsApp — нет. Лучше всего запустить бота и дать ссылку `t.me/...`, чтобы владелец сам записался для пробы.
4. Молчат 2–3 дня: одно напоминание (сообщение 3), и больше не пишите.
5. Отметьте статус в `leads/Leads-40.xlsx`.
