# Студия йоги «Гармония», ул. Владимира Пчелинцева, 4: бот расписания и записи

Предложение из таблицы top10 (№9): **сайт + бот расписания и записи на занятия**.
Зацепка: новая студия без отзывов, есть только группа ВК, нужен поток клиентов.

Дизайн спокойный и светлый, под йогу: песочный, шалфейный, терракота, шрифт с засечками.

- **Расписание на неделю** с количеством свободных мест (в группе 12). Когда группа набрана, запись закрывается сама.
- **Пробное занятие** за 300 ₽ при первой записи. Бот сам определяет новичка, студии в заявке приходит пометка «новичок 🌱».
- Телефон спрашивается **один раз**, дальше постоянный клиент записывается в одно касание.
- **Напоминание за 2 часа** с кнопками «Как добраться» и «Не смогу». При отмене место сразу освобождается.
- Для студии: уведомление о каждой записи, кнопка «Список группы», `/today` и `/tomorrow` со списками на каждое занятие, `/news текст` — новость всем клиентам (новое направление, мастер-класс, замена преподавателя).

| Файл | Что это |
|---|---|
| `demo.html` | Демо для владельца: мини-приложение в рамке телефона, справа чат студии и список на занятие. Вкладки: Расписание, Абонементы, Мои занятия, О студии |
| `webapp/index.html` | То же мини-приложение для Telegram (собирается из `demo.html` командой `./build_webapp.sh`). Его же можно выложить как сайт |
| `bot.py` | Бот (aiogram 3) |
| `banner.png`, `avatar.png` | Картинка на /start и аватарка бота |

Расписание, направления, имена преподавателей, цены абонементов и вместимость примерные, перед показом уточнить. Расписание задаётся в `SCHEDULE` и `CLASSES` в обоих файлах (`bot.py` и `demo.html`), вместимость в `CAPACITY`, цены в `TRIAL`/`SINGLE`.

## Запуск

```bash
pip install "aiogram==3.*"
BOT_TOKEN=xxx ADMIN_CHAT_ID=123456789 WEBAPP_URL=https://....netlify.app/ python bot.py
```

Подробно по шагам (BotFather, chat id, Netlify) в [`shinomontazh-bot/README.md`](../shinomontazh-bot/README.md#запуск). Если преподавателей несколько, удобно создать группу «Гармония: записи», добавить туда бота и указать id группы в `ADMIN_CHAT_ID`.

## Сообщения

**1. Первое сообщение**

> Здравствуйте! Меня зовут [Имя], я разрабатываю Telegram-ботов для онлайн-записи. Поздравляю с открытием студии! Заметил, что пока у вас есть только группа ВК. Могу предложить бота с расписанием занятий: запись в несколько касаний, напоминание за 2 часа до занятия и список участников для каждого занятия. Новой студии это помогает не терять клиентов, которые собирались прийти, но забыли. Будет ли вам интересно?

**2. После ответа «да»**

> Вот как это выглядит: [видео 30–40 сек или ссылка на демо]. Слева то, что видит клиент, справа то, что приходит вам, и список на занятие. Расписание, направления и цены поставлю ваши, запуск за 1–2 дня. Стоимость настройки — ___ ₽. Удобнее созвониться или встретиться в студии?

**3. Если молчат 2–3 дня (один раз)**

> Добрый день! Напомню про бота с расписанием и записью для «Гармонии». Если сейчас неактуально, просто напишите «нет», больше беспокоить не буду.

Правила отправки те же: [`shinomontazh-bot/README.md`](../shinomontazh-bot/README.md#как-отправлять-чтобы-whatsapp-не-забанил).
