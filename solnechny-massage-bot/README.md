# Кабинет массажа «Солнечный город», пр. Будённого, 21: Telegram-бот записи

Лид №10 из `leads/Leads-40.xlsx`. Тел./WhatsApp: **+7 953 359-03-67**. Мастер, судя по отзывам, Руслан. Сайт есть (`specmedreabilitation-rassokhin.ru`), поэтому предлагаем **Telegram-бота**.

**Что делает бот.** Клиент записывается сам или берёт курс из 10 сеансов. Бот напоминает накануне, после каждого сеанса пишет «сеанс 4 из 10, записаться на следующий?», поэтому курс реже бросают.

**Сосед по дому.** В доме 21к1 работает «Массаж, кинезиолог, остеопат» (лид №11), это конкурент.

## Файлы

| Файл | Что это |
|---|---|
| `demo.html` | Демо для владельца: мини-приложение записи в рамке телефона и чат владельца, куда падает заявка. Страницы: Запись, Цены, Мои записи, Контакты |
| `webapp/index.html` | То же мини-приложение для запуска внутри Telegram (собирается из `demo.html` командой `./build_webapp.sh`) |
| `bot.py` | Бот (aiogram 3): запись через мини-приложение или по шагам в чате, квитанция, «Мои записи», отмена, напоминание накануне, кнопки «Подтвердить / Отказать» у владельца, `/today`, `/tomorrow`, рассылка `/all`, учёт курса и приглашение через 3 дня |
| `banner.png`, `avatar.png` | Картинка на /start и аватарка бота |

Услуги, цены и часы задаются в `CONFIG` в начале `bot.py` и в `demo.html`. Сейчас они придуманы, сверху демо стоит пометка «Демо-версия». Запуск такой же, как у [`shinomontazh-bot`](../shinomontazh-bot/README.md#запуск): токен от @BotFather, chat id владельца, `webapp/index.html` выложить на Netlify.

## Как отправлять

1. Перед отправкой проверьте, что у номера есть WhatsApp или Telegram.
2. **Первое сообщение**: текст и скрин `screens/L10-solnechny-glavnaya.png`. Файл и ссылку не отправляйте.
3. Ответили «да»: отправьте второй скрин `screens/L10-solnechny-zayavka.png` (так заявка приходит владельцу) и сообщение 2. Демо-файл `dlya-otpravki/Massazh-Solnechnyy-gorod-bot.html` работает только в браузере, в предпросмотре WhatsApp — нет. Лучше всего запустить бота и дать ссылку `t.me/...`, чтобы владелец сам записался для пробы.
4. Молчат 2–3 дня: одно напоминание (сообщение 3), и больше не пишите.
5. Отметьте статус в `leads/Leads-40.xlsx`.
